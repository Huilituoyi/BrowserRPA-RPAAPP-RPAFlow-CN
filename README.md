# RPA 自动化助手

一款基于 PySide6 + Chromium 的 Windows 桌面 RPA（机器人流程自动化）工具。
集成内置浏览器、操作录制、多语言代码生成、定时任务调度、网页数据抓取、验证码识别和 Oracle 数据库操作，适用于各类网页自动化场景。

---

## 核心功能

### 内置浏览器
- 基于 Chromium 内核（QWebEngineView），完整的网页浏览能力
- 支持 User-Agent / 代理 / 窗口大小 / 无痕模式 / 忽略 SSL 错误等设置
- 右键菜单支持「复制定位器」（CSS / XPath / ID / Role / 文本）

### 操作录制 + 代码生成
- 类似 Playwright Codegen，实时捕获点击 / 输入 / 选择 / 按键等操作
- 录制完成后一键导出 **Python / JavaScript / TypeScript / C# / Java** 脚本
- 支持删除单步、上下移动排序
- 代码区域语法高亮，颜色可自定义

### 动作编辑（14 种动作类型）
录制或手动添加后，每条动作可在详情对话框中精细编辑：

| 类别 | 动作类型 | 说明 |
|------|----------|------|
| 基础 | navigate / click / fill / select_option / check / press / hover / scroll / wait | 页面导航与常规交互 |
| 验证码 | **fill_captcha** | 文字验证码 OCR 识别并自动填入 |
| 验证码 | **slide_captcha** | 滑块验证码（ddddocr 缺口识别 + 人工拖拽模拟） |
| 验证码 | **slide_right** | 滑块直接拖到最右侧（OCR 识别不准时的备选方案） |
| 控制流 | **mark** | 标记点，作为检查重试的跳转起点 |
| 控制流 | **check_retry** | 检查元素是否存在（可选校验**预期文本**），不通过则跳回标记点重试 |

每个动作支持 CSS / XPath / ID 三种选择器，并通过「拾取」按钮从内置浏览器中选取元素。

### 验证码识别（OCR）
- 内置 ddddocr 本地服务（Flask），无需联网
- **文字验证码**：自动识别图片中的字母数字并填入输入框
- **滑块验证码**：对比缺口图和背景图，计算缺口距离，模拟人工分步拖拽
- OCR 服务面板可启停、查看运行日志

### 定时任务调度
- 支持间隔触发 / Cron 表达式 / 一次性定时
- 全局并发控制（默认最多 3 个浏览器实例同时运行）
- 任务级锁（同一任务不会重复执行）
- 执行历史记录（最近 20 次，含耗时和错误信息）
- 任务完成后系统托盘通知
- 任务支持填写说明备注

### 网页数据抓取
- 按规则抓取（CSS 选择器 + 属性提取）
- 整表抓取（自动识别 `<table>`）
- **多页抓取**（翻页选择器 + 最大页数，自动翻页连续采集）
- 抓取结果导出 Excel 或写入 Oracle

### Oracle 数据库 -- 暂未完善
- 瘦模式连接（无需安装 Oracle 客户端）
- SQL 查询（自动分页，最多 5000 行）
- 所有操作在工作线程执行，不阻塞界面

### 其他
- 完整的日志系统（按天轮转 + 界面面板 + 控制台）
- 颜色自定义（语法高亮、日志级别、高亮色统一管理）
- 忽略 SSL 证书错误（同时作用于内置浏览器和 Playwright 回放引擎）

## 快速开始

### 环境要求

- Windows 10 / 11（64 位）
- Python 3.10+

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/yourname/RPAAPP.git
cd RPAAPP

# 2. 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 安装 Playwright 浏览器（约几百 MB，仅首次需要）
playwright install chromium

# 5. 运行
python main.py
```

## 使用指南

### 录制操作并生成代码

1. 打开「内置浏览器」标签页，输入目标网址
2. 点击工具栏「开始录制」按钮
3. 在网页中正常操作（点击、输入、选择等）
4. 操作完成后点击「停止录制」
5. 切换到「代码生成」标签页，选择目标语言
6. 复制或保存生成的代码

### 处理验证码

1. 打开「OCR 服务」标签页，点击「启动服务」
2. 在动作列表中添加对应类型的动作：
   - **文字验证码**：选 `fill_captcha`，填入验证码图片选择器和 OCR 地址
   - **滑块验证码**：选 `slide_captcha`，填入小图选择器、背景图选择器和 OCR 地址
   - **滑块拖到底**：选 `slide_right`，填入滑块按钮的选择器（OCR 不准时备用）
3. 录制回放时会自动调用 OCR 服务识别并操作

### 使用检查重试（控制流）

适用于需要等待页面状态变化或验证是否成功的场景：

1. 在需要重试的代码块前添加一个 **mark（标记点）** 动作
2. 在代码块后添加 **check_retry（检查重试）** 动作
3. 填写成功标志的 CSS 选择器（元素存在即成功）
4. 可选：填写「预期文本」，元素文本包含该值才算通过
5. 设定最大重试次数，不通过则自动跳回标记点重试

### 创建定时任务

1. 打开「定时任务」标签页，点击「新建任务」
2. 填写任务名称和说明，选择类型（回放动作 / 按规则抓取 / 抓取表格）
3. 配置触发方式（间隔 / Cron / 一次性）
4. 可选：设置每步间隔（回放）、翻页选择器（抓取）
5. 保存后可点击「立即运行」测试

### 抓取网页数据

1. 打开「数据抓取」标签页
2. 填入目标 URL 和抓取规则（CSS 选择器 + 属性）
3. 可选：填入翻页选择器和最大页数
4. 点击「抓取」按钮
5. 结果可导出为 Excel 或写入 Oracle

## 技术栈

| 组件 | 技术 |
|------|------|
| GUI 框架 | PySide6 (Qt6) |
| 浏览器引擎 | QWebEngineView (Chromium) |
| 自动化引擎 | Playwright (Python) |
| OCR 识别 | ddddocr + Flask |
| 数据库 | Oracle (oracledb 瘦模式) |
| 定时调度 | APScheduler |
| 数据导出 | openpyxl |

---

## 配置说明

用户配置文件位于 `data/config/app_config.json`，首次运行自动生成。

主要配置项：

| 配置段 | 说明 |
|--------|------|
| `browser` | UA / 代理 / 视口 / 超时 / 无痕模式 / SSL 忽略 |
| `oracle` | 主机 / 端口 / 服务名 / 用户名 / 密码 |
| `replay` | 每步最小/最大间隔、隐藏浏览器窗口 |
| `colors` | 语法高亮、日志、高亮背景的颜色（19 项） |

## 已知限制

- 仅支持 Windows 平台
- Playwright 浏览器二进制文件不包含在仓库中，需用户环境自行安装
- Oracle 操作仅支持查询（INSERT/UPDATE/DELETE 底层已实现，界面入口暂未提供）
